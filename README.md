# HCL-project
This final implementation of the Human-Computer Interaction project contains files for the interfaces of a digital library website for university students, whose purpose is to donate and request textbooks for courses.
## Features:
-Login system using ID number or academic number. 
-book browser by academic year or academic level. 
-add to cart and complete order.
-provide digital or physical books upon request.
## Technologies Used:
- HTML
- CSS
- JavaScript (Vanilla)
